# QYRA V1 Telemetry Dashboard

A lightweight, browser-based WebBLE dashboard utilized during early V1 breadboard testing. 
Built to rapidly validate the FreeRTOS dual-bus sensor polling loop and local triage thresholds before migrating the frontend architecture to the production Flutter application.

**User Guide:** Open `index.html` in any Chromium-based browser supporting the Web Bluetooth API to connect directly to the ESP32-S3 node.
